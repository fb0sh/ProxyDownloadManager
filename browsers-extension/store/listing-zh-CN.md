## 扩展名称

Proxy Download Manager

## 简短说明（来自 manifest，只读）

把浏览器下载交给 ProxyDM 桌面端：每个任务独立选代理，多线程加速、断点续传。

## 说明

Proxy Download Manager（ProxyDM）浏览器扩展把下载从浏览器手里接过来，交给免费开源的 ProxyDM
桌面端。ProxyDM 是一款多代理下载管理器：每个下载任务可独立选择 HTTP / SOCKS5 代理，可在多个候选
代理之间自动切换，单文件最高 64 线程并发，并支持断点续传。

**为什么装它**

- **让下载走代理。** 按任务挑代理，或准备一组候选线路，某条失败时自动换下一条。
- **大文件更快。** 多线程并发、按文件大小自适应连接数，失败自动重试并轮换 User-Agent。
- **浏览器不掺和。** 扩展在浏览器真正开始下载之前就把它截住，连同 URL、Cookie、Referer 和
  User-Agent 一起交给桌面端，让下载请求和你点的那一次完全一致。

**扩展做什么**

- **拦截下载。** ProxyDM 运行时，你触发的下载会被送到桌面端并弹出「新建下载」窗口，可以在开始前
  确认保存目录、线程数和代理。
- **右键菜单。** 在链接上、页面上，或选中的一批链接上使用「Download with ProxyDM」。
- **本页媒体。** popup 列出当前页面里发现的媒体文件（视频、音频，以及常见的压缩包与安装包类型），
  点一下就能交给 ProxyDM。
- **跳过下一次下载。** 一键武装一次性的旁路，或按住 Alt / Delete 点击，这一次让浏览器自己下载。
- **过滤器。** 设置最小文件体积，并按域名、扩展名忽略，让小的或不想管的文件继续走浏览器。
- **连接状态。** 工具栏角标和 popup 显示桌面端是否已连接；桌面端没在运行时，会弹一条通知说明这次
  为什么回退到浏览器下载。
- **界面支持 English 与简体中文。**

**需要桌面端**

这个扩展是配套工具，不是独立的下载器。桌面端没在运行时，它保持空闲并显示「未连接」——角标变暗，
下载照常走浏览器。桌面端免费开源（MIT）：
https://github.com/fb0sh/ProxyDownloadManager/releases

**隐私**

扩展只和你自己机器上的桌面端通信（`ws://127.0.0.1:18999`），不会向开发者或任何第三方发送任何内容。
它读取你正在下载的那个 URL 的 Cookie 与响应头，唯一目的是让桌面端复现同一个请求。
隐私政策：https://fb0sh.github.io/ProxyDownloadManager/privacy.html
