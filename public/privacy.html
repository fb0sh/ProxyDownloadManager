Privacy Policy — Proxy Download Manager

Applies to the Proxy Download Manager browser extension (Chrome, Edge, Firefox) and the ProxyDM desktop application. Last updated: 24 September 2026.

Proxy Download Manager is free and open source. This policy explains exactly what the extension and the desktop app do with data. Every statement below can be checked against the source code at github.com/fb0sh/ProxyDownloadManager.

Summary

  • The extension communicates only with the ProxyDM desktop app running on the same computer, over ws://127.0.0.1:18999 (loopback).
  • No data is sent to the developer or to any third party. There is no analytics, no telemetry, no advertising and no user account.
  • The extension works with the machine offline.
  • Settings and per-tab state are stored locally in your browser profile and are removed when you uninstall the extension.

What the extension accesses, and why

DataHow it is obtainedWhat it is used for
The URL, file name, MIME type and originating tab address of a download you start Browser downloads API To hand the download to the desktop app, then cancel and clear the browser's own copy so the file is not fetched twice.
Cookies for the download URL Browser cookies API, queried for that single URL So the desktop app can make the same request the browser would have made (for example, for a file behind a login). Cookies are passed to the local app in memory for that request only.
A fixed allow-list of eight request headers — cookie, referer, origin, user-agent, authorization, accept, accept-language, accept-encoding Browser webRequest API (read-only) and the download event To reproduce the user's request faithfully. Every other header is discarded by the extension and never leaves the browser.
Response Content-Type and Content-Length Browser webRequest API, read-only To tell a downloadable file apart from a streaming response, show the correct size, and build the media list in the popup.
Media elements (video, audio, archive and installer links) found on the page you are viewing Content script reading the page's own DOM To list them in the popup so you can send one to the desktop app. Content is read, never modified.
Your settings: capture on/off, minimum file size, ignored domains, ignored extensions Entered by you in the popup Stored locally with chrome.storage.local so your preferences survive restarts.

Where data goes

  • The data listed above is sent over a loopback WebSocket to the ProxyDM desktop app on the same machine, and nowhere else. The desktop app only listens on 127.0.0.1; it exposes no inbound port to your network or the internet.
  • The desktop app uses those details to perform the download you asked for, through the proxy you configured. It redacts the values of Cookie, Authorization, Proxy-Authorization and Set-Cookie in its own log output.
  • The developer operates no server that receives extension or app data, and has no way to read your downloads, browsing history or settings.
  • Data is not sold, rented or shared with anyone, and is not used for advertising, profiling or creditworthiness.
  • Data is not used for any purpose unrelated to the single purpose of sending your downloads to your own desktop app.

Retention and deletion

  • Extension settings live in your browser profile until you change them or uninstall the extension; uninstalling removes them.
  • Per-tab media state is held in session storage and disappears with the session.
  • Download records and files on disk are managed by the desktop app under your control; delete them from the app, or delete the files from your file system.
  • Because the developer receives nothing, there is no server-side copy to request or delete.

Children

The extension is not directed at children and does not knowingly collect personal information from anyone, including children.
